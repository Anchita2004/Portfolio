Incremental Orders Pipeline (PySpark + Delta Lake)

  • Databricks pipeline that loads daily order CSVs, rejects bad rows to a quarantine table, removes duplicates and keeps one up-to-date row per order using Delta Lake MERGE.
  • Idempotent by design: a file is logged only after it fully succeeds, so re-runs never create duplicates.
  • Result after 3 daily files: 600 orders, 0 duplicate order IDs, 60 orders updated by later files, 3 invalid rows quarantined per file.
